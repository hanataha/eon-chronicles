# The Eon Chronicles – Character Wiki

A fan-made, family-friendly character wiki for an original fantasy story cycle: seven sovereign women, six worlds, and the Dreamer called Eon who walks between them.

Static HTML/CSS/JS with hash routing, no build step. Open `index.html` or serve the folder with any static server.

- `data.js` – all wiki content (characters, chronicles, places, world)
- `app.js` – router and renderers
- `styles.css` – dark fantasy theme (mobile-first)
- `images/characters/` – the seven character portraits
